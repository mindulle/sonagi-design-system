# 텍스트에어리어 (Textarea)

수직 리사이즈를 지원하며, Input과 동일한 2px 경계선 및 포커스 링 스타일을 계승합니다.

<ComponentPreview name="Textarea" />

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `rows` | `number` | `3` | 기본 표시 줄 수 |
| `error` | `boolean` | `false` | 에러 상태 여부 |
| `disabled` | `boolean` | `false` | 비활성화 여부 |
