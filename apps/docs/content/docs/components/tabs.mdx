# 탭 (Tabs)

가로 스크롤 및 포커스 링을 지원하며, `Tabs.Container`와 `Tabs.Item`의 합성 컴포넌트로 동작합니다.

<ComponentPreview name="Tabs" />

## 사용 예제

```tsx
import { Tabs } from '@mindulle/ui';

export function TabExample() {
  const [tab, setTab] = useState('all');

  return (
    <Tabs.Container>
      <Tabs.Item isActive={tab === 'all'} onClick={() => setTab('all')}>
        전체보기
      </Tabs.Item>
      <Tabs.Item isActive={tab === 'docs'} onClick={() => setTab('docs')}>
        문서
      </Tabs.Item>
    </Tabs.Container>
  );
}
```
