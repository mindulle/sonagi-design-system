# 아코디언 (Accordion)

The True 2px Stem 경계선과 4px 모듈러 곡률이 적용된 접이식 컴포넌트입니다.

<ComponentPreview name="Accordion" />

## 사용 예제

```tsx
import { Accordion } from '@mindulle/ui';

export function AccordionExample() {
  return (
    <Accordion.Container>
      <Accordion.Item title="MDS v0.1.0이란 무엇인가요?" defaultExpanded>
        민들레 디자인 시스템 공식 규격입니다.
      </Accordion.Item>
      <Accordion.Item title="조형 언어 원칙">
        The True 2px Stem, 4px Weathered Radius, No Soft Shadows
      </Accordion.Item>
    </Accordion.Container>
  );
}
```
