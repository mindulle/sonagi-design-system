# 뱃지 (Badge)

상태(info, success, warning, danger) 및 메타데이터를 간결하게 표시하는 컴포넌트입니다.

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `variant` | `'pill' \| 'label'` | `'pill'` | 알약형 둥근 형태 또는 직각 라벨 형태 |
| `color` | `'info' \| 'success' \| 'warning' \| 'danger'` | `'info'` | 시맨틱 상태 컬러 |
| `children` | `React.ReactNode` | — | 뱃지 텍스트 |
