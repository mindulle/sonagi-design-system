# 체크박스 (Checkbox)

라벨과 서브 설명(description)을 함께 배치할 수 있으며, 불확정(indeterminate) 상태를 지원합니다.

<ComponentPreview name="Checkbox" />

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `label` | `React.ReactNode` | — | 주 라벨 텍스트 |
| `description` | `React.ReactNode` | — | 부차적 설명 텍스트 |
| `indeterminate` | `boolean` | `false` | 불확정 중간 상태 |
| `disabled` | `boolean` | `false` | 비활성화 여부 |
