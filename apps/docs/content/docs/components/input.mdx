# 인풋 (Input)

MDS 인풋 컴포넌트는 The True 2px Stem 경계선과 포커스 링, 에러 상태 피드백을 제공합니다.

## Props 명세

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `error` | `boolean` | `false` | 유효성 검사 에러 상태 여부 |
| `disabled` | `boolean` | `false` | 입력 비활성화 여부 |
| `placeholder` | `string` | — | 힌트 텍스트 |
