# 빠른 시작 (Quickstart)

민들레 디자인 시스템(MDS)은 **W3C 표준 디자인 토큰**과 **React 기반 UI 컴포넌트**로 구성된 실무 디자인 시스템입니다.

## 1. 패키지 설치

GitHub Packages 레지스트리를 통해 토큰 및 UI 패키지를 설치합니다:

```bash
pnpm add @mindulle/tokens @mindulle/ui @mindulle/icons
```

## 2. 글로벌 스타일 주입

앱의 진입점(`layout.tsx` 또는 `main.tsx`)에 디자인 토큰 CSS와 컴포넌트 스타일을 불러옵니다:

```tsx
// 토큰 CSS Custom Properties (--mds-* / --sng-*)
import '@mindulle/tokens/css';

// MDS 컴포넌트 기본 스타일
import '@mindulle/ui/css';
```

## 3. 컴포넌트 사용

컴포넌트를 임포트하여 바로 화면을 구성합니다:

```tsx
import { Button, Badge, MindulleLogo } from '@mindulle/ui';

export default function MyPage() {
  return (
    <div className="p-6 space-y-4">
      <div className="flex items-center gap-2">
        <MindulleLogo size={32} />
        <h1 className="text-xl font-bold">민들레 스튜디오</h1>
        <Badge variant="pill" color="success">활성</Badge>
      </div>

      <p className="text-sm opacity-80">
        겨울 끝, 민들레. 비바람에도 꺾이지 않는 선명한 2px Stem과 4px 모듈러 곡률.
      </p>

      <Button variant="primary" size="md">
        시작하기
      </Button>
    </div>
  );
}
```

## 4. 라이트 / 다크 모드 전환

MDS는 HTML 엘리먼트의 `data-theme` 속성을 통해 모드를 제어합니다:

```html
<!-- 라이트 모드 (웜 스톤 & 앰버 골드) -->
<html data-theme="light">

<!-- 다크 모드 (회색돌 다크 #12151d & 민들레 골드 #ffc837) -->
<html data-theme="dark">
```
