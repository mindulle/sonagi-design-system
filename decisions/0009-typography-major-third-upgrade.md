# ADR 0009: Desk Analyst 테마 폐기 및 Major Third(1.25) 스케일 격상

## Status

**Accepted**

## Context

과거 'Desk Analyst' (밀도 높은 데이터 대시보드) 프로젝트와의 공존을 위해, '가을 소나기'의 에디토리얼 테마가 원했던 넓고 시원한 폰트 스케일을 포기하고 좁은 1.200 (Minor Third) 스케일을 억지로 채택했던 뼈아픈 타협(ADR 0002)이 존재했다.

최근 Desk Analyst 프로젝트가 공식 폐기됨에 따라, 더 이상 폰트 스케일을 좁게 유지할 이유가 사라졌다. 또한 직전 의사결정([ADR 0008](./0008-typography-ui-document-separation.md))을 통해 UI 컴포넌트용 타이포그래피 트랙이 완벽히 분리되었으므로, 문서(Document)용 스케일을 대폭 확장하더라도 UI 컴포넌트는 전혀 붕괴하지 않는 방탄(Bulletproof) 아키텍처가 확보되었다.

## Decision

1. **Desk Analyst 코드 척결**: 코드베이스 및 빌드 파이프라인에서 Desk Analyst 테마와 관련된 모든 JSON 및 예외 코드를 영구 삭제한다.
2. **Major Third (1.250) 스케일 격상**: 기준 폰트 16px을 바탕으로 1.25배씩 증가하는 황금 비율(Major Third)을 전격 도입하여, 시원하고 감성적인 에디토리얼 타이포그래피 시스템을 완성한다.

| 기존 토큰 | 기존 값 (1.2) | 새 토큰 스케일 (1.25) | 변경된 픽셀 |
| --------- | ------------- | --------------------- | ----------- |
| 5xl (H1)  | 48px          | 16 \* (1.25^4)        | **61px**    |
| 4xl (H2)  | 40px          | 16 \* (1.25^3)        | **49px**    |
| 3xl (H3)  | 33px          | 16 \* (1.25^2)        | **39px**    |
| 2xl (H4)  | 28px          | 16 _ 1.25 _ 1.25      | **31px**    |
| xl (H5)   | 23px          | 16 \* 1.25            | **25px**    |
| lg (H6)   | 19px          | 16 \* 1.25 (보정)     | **20px**    |
| base      | 16px          | 기준점                | **16px**    |
| sm        | 13px          | 16 / 1.25             | **13px**    |
| caption   | 11px          | 16 / 1.25 / 1.25      | **10px**    |

## Consequences

- **Positive**: '가을 소나기' 테마의 본질인 감성적이고 시원한 글읽기 경험이 극대화된다.
- **Positive**: 무의미한 레거시 테마(Desk Analyst)가 삭제되어 시스템 용량과 빌드 속도가 최적화된다.
