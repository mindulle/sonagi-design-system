# 🎨 Sonagi Design System Tokens

Sonagi 디자인 시스템의 모든 디자인 토큰 명세입니다. 이 토큰들은 `@mindulle/tokens` 패키지에서 빌드되어 CSS Custom Properties로 주입됩니다.

---

## 1. Colors (색상)

**V3 아키텍처 업데이트 (2026-08)**: 
이전 V2의 Navy/Blue 테마에서 벗어나, 특유의 단단하고 따뜻한 감성을 담은 **Burgundy & Brown** 기반의 색상 체계로 전면 개편되었습니다.

모든 시맨틱 색상은 \`var(--sng-color-*)\` 형태로 사용할 수 있으며, 다크모드 적용 시 자동으로 알맞은 Primitive 값으로 스왑(Swap)됩니다.

### Brand Colors (브랜드 컬러)
- **`--sng-color-brand-primary`**: 메인 브랜드 컬러 (버튼 배경 등)
- **`--sng-color-brand-primary-hover`**: 메인 브랜드 컬러 호버 상태
- **`--sng-color-brand-accent`**: 보조 강조 컬러 (뱃지, 포인트)
- **`--sng-color-brand-cyan`**: 로고 및 심볼용 시그니처 옥색 점(`#00ffcc`)

### Background Colors (배경 컬러)
- **`--sng-color-background-base`**: 최하단 도화지 배경
- **`--sng-color-background-surface`**: 1단계 돌출된 카드/입력창 배경
- **`--sng-color-background-elevated`**: 2단계 부유하는 팝업/모달 배경

### Text Colors (텍스트 컬러)
- **`--sng-color-text-primary`**: 기본 텍스트 (가장 높은 가독성)
- **`--sng-color-text-secondary`**: 보조 텍스트 (설명, 서브타이틀)
- **`--sng-color-text-muted`**: 비활성/힌트 텍스트
- **`--sng-color-text-inverse`**: 짙은 배경 위 반전 텍스트

## 2. Typography (타이포그래피)

Sonagi 시스템은 Minor Third(1.2) 스케일을 기반으로 한 수학적인 타이포그래피 스케일을 제공합니다.
피그마의 `UI / Body 16`, `UI / Label 14` 등의 텍스트 스타일과 1:1로 매칭됩니다.

- **Title (18px)**: `--sng-typography-ui-title-18-*`
- **Body (16px)**: `--sng-typography-ui-body-16-*`
- **Label (14px)**: `--sng-typography-ui-label-14-*`
- **Body (14px)**: `--sng-typography-ui-body-14-*`
- **Detail (12px)**: `--sng-typography-ui-detail-12-*`

> 주의: 오프스케일(예: 24px) 텍스트는 허용되지 않으며, 피그마 상에서 반드시 공식 스케일로 스냅(Snap)되어야 합니다.

---

## 3. Shadows (그림자)

부유(Elevation) 계층을 시각적으로 구분하기 위해 3단계의 그림자를 지원합니다.

- **`--sng-shadow-flat`**: 그림자 없음
- **`--sng-shadow-raised`**: 버튼, 카드 등 살짝 돌출된 요소
- **`--sng-shadow-floating`**: 호버 프리뷰, 모달 등 높이 떠있는 요소
- **`--sng-shadow-focus`**: 키보드 접근성(Focus Ring)을 위한 아웃라인 효과
